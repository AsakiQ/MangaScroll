# MangaScroll

Авточиталка для ReManga под Windows x64. Открой мангу в Chrome, задай темп и читай, пока страницы плавно прокручиваются. В одном тёмном окне можно управлять сразу несколькими главами.

**[Скачать MangaScroll-Dark.exe](https://github.com/AsakiQ/MangaScroll/raw/refs/heads/main/dist/MangaScroll-Dark.exe)** · [Релизы](https://github.com/AsakiQ/MangaScroll/releases)

## Быстрый старт

1. Открой главу ReManga в отдельном окне Google Chrome. Для второй манги открой ещё одно окно.
2. Запусти EXE, нажми **Обновить**, выбери окно по названию главы и нажми **Добавить окно**.
3. Нажми **▶** в нужной строке или **Пуск всех**. Чтобы изменить темп во время чтения, сначала поставь окно на паузу.

## Управление чтением

| Элемент | Что делает |
| --- | --- |
| Шаг от / до | Задаёт диапазон прокрутки. 120 единиц соответствуют одному щелчку колеса. |
| Мс от / до | Задаёт паузу между шагами в миллисекундах. Для постоянного темпа укажи одинаковые границы в обоих диапазонах. |
| Отправлять | Включает автоматическую отправку текста из поля **Комментарий** в конце главы. По умолчанию выключено. |
| Состояние | Показывает ход чтения и причину остановки. Подробности и расшифровка кодов доступны через **Ошибки**. |
| ▶ · Ⅱ · × | Запустить, приостановить или убрать строку после паузы. Окно Chrome остаётся открытым. |

В конце главы читалка пытается перейти к следующей. Скорость и текст комментария задаются отдельно для каждого окна.
